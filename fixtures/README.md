# Evaluation fixtures

The demo fixture set should include:

- `policy-current.md`: current public policy and labelled questions.
- `policy-superseded.md`: old version containing conflicting wording.
- `restricted-notice.txt`: staff-only fact used for leakage tests.
- One born-digital PDF with headings/pages.
- One difficult born-digital PDF where warnings are expected.

Evaluation is intentionally small and manually checked. Labels live in `evaluation.json`.
