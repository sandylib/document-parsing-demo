# Evaluation fixtures

Checked-in content:

- `policy-current.md`: current public policy.
- `policy-superseded.md`: old version containing conflicting wording.
- `restricted-notice.txt`: staff-only fact used for access checks.
- `evaluation.json`: three labelled retrieval questions.
- `providers/openai-chat-stream.txt`: provider stream fixture.

There are no checked-in PDF fixtures. Earlier manual PDF observations are identified as historical in the evaluation report. Representative PDF, Word, scan, table and layout cases are proposed production/pilot validation in the solution design, not completed coverage.

The retrieval script checks expected text or empty results. It does not calculate parsing accuracy, Recall@k or generated-answer quality.
